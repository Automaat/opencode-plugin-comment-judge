# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text is at that link.

The short version:

- Be direct about code and decent about people.
- Assume the other person had a reason, and ask what it was.
- Disagreement is most of what review is for. Once something is decided, argue it in an issue rather than in every later pull request.
- No harassment, demeaning comments or unwelcome attention, in issues, pull requests, reviews, commit messages or anywhere else this project happens.

## Reporting

Report conduct issues to the maintainer, [@Automaat](https://github.com/Automaat), privately through [GitHub's private reporting form](https://github.com/Automaat/opencode-plugin-comment-judge/security/advisories/new) with "Code of conduct" in the title, or through GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature. Reports are handled privately.
